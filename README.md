**Copper Ladle — Rush Hour Kitchen**: an original 2D canvas cooking game. Customer tickets land on the order board; grab ingredients from the counter bins, chop on the board, grill till READY (never BURNT), build each dish on a plate, and serve it at the pass before the ticket's patience bar runs dry. Seven recipes that unlock and combine in different ways across a 150-second day, faster and tighter tickets as the rush builds, combo bonuses for clean service, and three walk-outs ends the day. Keyboard and mouse, no build step, no network: every file is static under `game/`.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```
